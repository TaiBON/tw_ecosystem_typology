# S2 地下人造洞穴生物群系

地下礦坑隧道。

地下人造洞穴生物群系是歸因於人類挖掘行為形成的單一功能生態群系。 出現於地下礦坑、運輸隧道、墓穴、防禦和能源設施和其他基礎建設。 大多是於工業時代用土方機械建構而成的，部分是數千年前手工建造。 生產力低，能量通常來自地表大氣擴散或滲漏而來，部分能量是由化學自營微生物提供。 雖然沒有日照或光線高度漫射，但一些活動洞穴有人工照明，提供充足能量來維持藻類自營。 營養網主要由伺機性微生物和無脊椎動物組成，透過機械、人類直接引入或自行由洞穴開口進入。 後者包括利用洞穴作為庇護所或繁殖地的小型哺乳動物。 外來及原生的微生物迅速定植於新暴露的岩石表面，並形成生物膜供給食碎屑動物並加速基質風化。 地下人造洞穴的穩定性受基質和管理方式而變化，部分洞穴廢棄後容易發生坍塌和結構變化。

# S2.1 地下人造洞穴

群系: 地下人造洞穴
生態域: 地下

## 生態特徵

充滿空氣的低生產力地下洞穴是由人為開鑿而成。 雖與富氧洞穴（S1.1）相似，但其結構較為簡單、形成時間較短、地質變異性更高、缺乏演化與特有種，使得生物多樣性較低。 由於人為發展所引發的奠基者效應（founder effects），即拓殖事件稀少、演化分歧時間不足，加上洞穴牆面結構單純，導致微棲地類型多樣性低，使得生物多樣性低、特有種少與機會主義的生物特徵。 營養網絡由異營生物主導，缺乏光合自營生物與食草動物。 廣食性腐食者及其病原體與掠食者佔多數，專食性物種與蝙蝠糞堆相關， 包括無脊椎動物（多為甲蟲、跳蟲與蛛形綱）、真菌、細菌與暫態脊椎動物，尤以蝙蝠常將洞穴作為棲息與繁殖場所。 細菌與真菌在洞穴岩壁形成生物膜， 真菌及細菌多為人類活動引入，部分被識別為「人類指標菌」，如大腸桿菌（Escherichia coli）、金黃色葡萄球菌（Staphylococcus aureus）與高溫型芽孢桿菌屬（Bacillus spp.）。 潮濕的微棲地中，真菌豐度最高， 部分為寄生蟲，是無脊椎動物與原生動物的重要食物來源。 能量與養分來源皆為異源輸入，經由人類、蝙蝠、有翼無脊椎動物、其他動物或滲入的水分輸入。 許多物種具有長壽命、生長代謝緩慢、繁殖力低的特徵，並且不具有自然洞穴生物常見的適應性性狀。 一些物種為暫時性的地下棲息者，族群完全分布於地上或地下，抑或是生活史需要利用兩種環境。

## 關鍵生態驅動力

隧道、地下室與礦坑等開挖作業所形成。 部分空間已廢棄，部分仍持續利用，使地下與地表的連通性、資源輸入與生物擴散增加。 基質包括多種岩石類型，包含人造襯料與瓦礫堆。 空氣流動變化從靜止到劇烈（如列車隧道）。 除非在開口或有人造光源的地點（例如 燈源植物相），能支持藻類的生長，否則普遍缺乏光線。 濕度與溫度相對穩定，營養資源稀缺，受人為資源輸入變化。

## 生態系功能群分布

全球零星分布，主要與城市中心、交通廊道與工業礦區相關。
